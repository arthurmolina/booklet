booklet

PDF imposition tool for signature booklet printing.

Python 3 PyMuPDF MIT

What it does

Takes any PDF and rearranges its pages into folded signatures — a stack of nested sheets that, when printed duplex and folded, read in the correct order. The output PDF has two source pages side by side on each landscape sheet.

Pages are grouped into signatures of up to N sheets (default: 4 sheets = 16 pages). If the total page count isn't a multiple of 16, the last signature uses fewer sheets and is padded with blank pages to the nearest multiple of 4.

Signature layout

For a 4-sheet signature (16 pages), the imposition order is:

Sheet 1 · front
161
Sheet 1 · back
215
Sheet 2 · front
143
Sheet 2 · back
413
Sheet 3 · front
125
Sheet 3 · back
611
Sheet 4 · front
107
Sheet 4 · back
89

Front pages are printed first; back pages are the reverse side of each sheet. Nest all sheets together, fold in half, and bind or stitch the spine.

Installation

Requires Python 3 and PyMuPDF:

pip install pymupdf

Clone the repo and install the command:

git clone https://github.com/arthurmolina/booklet
cd booklet
chmod +x booklet.py
ln -s "$(pwd)/booklet.py" ~/.local/bin/booklet

Usage

booklet <input.pdf> <output.pdf> [options]
OptionDefaultDescription
-s, --sheets N 4 Maximum sheets per signature
-h, --help — Show help message

Examples

# Default: signatures of 4 sheets (16 pages each)
booklet book.pdf booklet.pdf

# Smaller signatures — good for thinner paper or stapling
booklet book.pdf booklet.pdf --sheets 2

# Single-sheet signatures (4 pages each)
booklet book.pdf booklet.pdf -s 1

Printing

Print the output PDF duplex with long-edge flip (flip on the left/right axis — the default duplex mode for landscape pages on most printers).

After printing, sort the sheets by signature, nest each group together, fold in half, and bind or stitch the spines.
